Table users
Structure de la base de données
Chaque colonne a un rôle précis dans le cycle de vie du compte.
password Bcrypt
Jamais stocké en clair. Hash de 60 caractères.
verify_token 64 hex
Mis à NULL après confirmation. Usage unique.
email_verified tinyint
0 = en attente, 1 = confirmé. Bloque la connexion si 0.
reset_token_expires datetime
Expiration 1h. Vérifié via reset_token_expires > NOW().
deleted_at Soft delete
Le compte n'est pas supprimé physiquement, juste exclu des requêtes.
CREATE TABLE users (
  id                INT AUTO_INCREMENT,
  prenom           VARCHAR(100),
  email            VARCHAR(150) UNIQUE,
  password         VARCHAR(255),
  role             ENUM('user','admin'),
  verify_token     VARCHAR(100),
  email_verified   TINYINT DEFAULT 0,
  reset_token      VARCHAR(100),
  reset_token_expires DATETIME,
  deleted_at       DATETIME,
  PRIMARY KEY (id)
);
